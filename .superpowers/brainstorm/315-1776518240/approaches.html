优点

  • 改动最小 — 只改 prompt 和切割逻辑
  • AI 画内容比画黑格靠谱得多
  • 所有格子都有内容，分隔线更一致

注意

  • 需要设计好的占位提示词
  • 多消耗一点点 API 资源

优点

  • 减少空格数量，降低出错概率
  • 配合方案A效果更好

缺点

  • 需要改 calculateGridSize 逻辑
  • AI对非方形网格可能更难遵循
  • 切割逻辑也要适配矩形

方案 C：Prompt 强化 + 重实验证

强化提示词约束 + 生成后自动检测分隔线 + 失败自动重试

优点

  • 从根本上提升质量
  • 对所有网格尺寸都有帮助

缺点

  • 开发量大（需要图像检测）
  • 重试增加成本和延迟
  • 复杂度高，效果不一定好

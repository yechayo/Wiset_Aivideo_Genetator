改动 1：PanelPromptBuilder.buildGridPrompt

替换空格填充逻辑

BEFORE
// 空格填充
for (int i = actualCount; i < totalSlots; i++) {
  sb.append("格子").append(i+1)
    .append(": 纯黑色填充，不绘制任何内容\n");
}
AFTER
// 占位场景填充
for (int i = actualCount; i < totalSlots; i++) {
  String filler = pickFillerScene(
    visualStyle, i - actualCount);
  sb.append("格子").append(i+1)
    .append(": ").append(filler).append("\n");
}

改动 2：GridImageService.splitGridImage

切割时丢弃多余格子，只返回实际分镜对应的图片

BEFORE
// 切割所有格子
for (int r = 0; r < rows; r++) {
  for (int c = 0; c < cols; c++) {
    // 切割并上传
  }
}
// 返回所有格子图片
AFTER
// 只切割实际分镜数
int index = 0;
for (int r = 0; r < rows && index < actualCount; r++) {
  for (int c = 0; c < cols && index < actualCount; c++) {
    // 切割并上传
    index++;
  }
}
// 多余格子直接跳过

改动 3（新增）：pickFillerScene 方法

新增一个小方法，根据视觉风格从预设池选取占位场景

private String pickFillerScene(String visualStyle, int index) {
  List<String> pool = FILLER_POOL.getOrDefault(
    visualStyle, FILLER_POOL.get("DEFAULT"));
  return pool.get(index % pool.size());
}
